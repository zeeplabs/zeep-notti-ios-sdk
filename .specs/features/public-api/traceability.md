## 3. Spec deviations recorded during Execute

| Task | Deviation | Applied to |
| --- | --- | --- |
| T3 | The listener recipient list is snapshotted when the event is received, not when the main-thread block runs. The replay inside `attach` therefore reaches only the first listener even if a second is added before main runs; a listener removed before its turn is still skipped at call time | design.md (`NottiListenerHub`), spec API-10 AC 3 unchanged |
| T4 | `NottiPayloadKeys` has no title/body/data constants (`toEventPayload()` hardcodes them), so `NottiNotificationPayload` keeps private key constants; the handler round-trip tests catch drift. No public initializer | design.md (Data Models) |
| T5 | The `http://` rejection depends on the build configuration (Debug accepts it, NottiApiClient A5): the test asserts the Debug rule under `#if DEBUG` | spec Edge Cases |
| T6 | A pre-initialize `setEmail` was lost when `start` replaced the ensured core (queued core blocks capture `self` weakly). `NottiRuntime.invalidateCurrentCore` now keeps the replaced core alive until its queue drains (bounded 60 s wait on a utility thread). No core file changed | design.md (`NottiRuntime` additions), STATE.md |
| T9 | The public level enum is the top-level `@objc(NottiLogLevel) public enum NottiLogLevelObjC`, and `Notti.LogLevel` is a typealias of it (T1 spike: a nested `@objc` enum is not exported to ObjC) | design.md (Public types), spec Assumptions |
| T12 | `NottiSubscription` inherits `NSObject` (`@objc(NottiSubscription)`, `@objc remove()`) so ObjC hosts can hold it. ObjC listeners receive an `NSDictionary` (`title`/`body` only when present, `data` always) because `NottiNotificationPayload` is a Swift struct. The ObjC classes are also visible to Swift as `NottiObjC`, `NottiUserObjC`, `NottiNotificationsObjC` | design.md (Objective-C layer) |
| T13 | Surface entries are `path: declaration` (line numbers dropped), multi-line parameter lists are joined, and the script has `--update` | design.md (Public surface guard) |
