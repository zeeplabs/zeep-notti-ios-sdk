## 3. Findings and recorded decisions

| Item | Where | Note |
| --- | --- | --- |
| D1 end-of-launch fallback | `NottiFallbackDelegateAssigner`, `NottiDelegateInstaller` | The installer observes the launch notification once and keeps a `launchFinished` flag. An install after launch (the `Notti.initialize` path) evaluates the assigner immediately. Without it the fallback was never assigned for a late install |
| D2 narrowed presentation | `NottiPushAdapter.willPresent` | Confirmed by Julio (2026-10-11) |
| `install()` vs `ensureInstalled()` | `NottiDelegateInstaller` | `+install` is the `+load` entry (no UIKit probe). `Notti.initialize` calls `ensureInstalled()`, the same idempotent install plus a look at delegates that already exist. The task text says `install()` for both |
| Lazy runtime in the adapter | `NottiPushAdapter(runtimeProvider:)` | Needed for DEL-14: building the production adapter at `+load` must not create `NottiRuntime.shared` (UserDefaults, observers) |
| `UNUserNotificationCenter.current()` can raise | `NottiCurrentNotificationCenter` | In a process with no bundle proxy (the XCTest agent) it raises `NSInternalInconsistencyException` even though `bundleIdentifier` is set. The lazy center returns nil unless the main bundle is an `.app` |
| `+load` also runs in the test process | `IN.test_theLaunchHookInstalledTheRealSwizzlesInThisProcess` | The real `UIApplication` / `UNUserNotificationCenter` setters are swizzled for the whole xctest run. The other suites inject their own classes and state; the full suite stayed green and no interference was found |
| `setDelegate:` is an instance method | design.md text | design.md said "class method"; the code is right. Text corrected on disk |
| Pod hook proof uses the Core subspec | `scripts/check-hook-linked.sh pod` | `pod lib lint` over all subspecs rebuilds the same product directory per subspec, so the kept product is the last one (Extension). The check lints `--subspec=Core --no-clean` |
| Open items for Julio | design.md | (1) `NottiDisableSwizzling` as the public key name, (2) pure passthrough for the deep link until the backend defines a standard URL key |
